# Specs

Each stage's rules, test and pass bar, written before its runs, with the results added afterwards. They were working
documents, so they're terse, and "the user" means the project's owner. Private machine names and paths have been
replaced with neutral wording; the engineering and the results are unchanged.

| Spec | Stage | Outcome |
|---|---|---|
| [Predator-prey crucible](2026-10-14-predprey-crucible-design.md) | 1: two species learn from nothing | PASS, then a stalemate |
| [Evolution](2026-10-14-evolution-design.md) | 2: heritable bodies and plants | PASS, but only meaningful against its control |
| [Terrain](2026-10-14-terrain-design.md) | 3: walls and burrows | FAIL (burrow use did not emerge) |
| [Memory](2026-10-14-memory-design.md) | 4: seasons and recurrent brains | FAIL |
| [Speciation](2026-10-14-speciation-design.md) | 5a: size, mating, two foods | FAIL, six versions |
| [Stored meals](2026-10-30-fatprey-design.md) | 5b: a viewer's idea, a meal worth what the prey stored | FAIL twice, the second a fair retest; closed |
| [Pack hunting](2026-10-14-pack-hunting-design.md) | 6a: two hunters per catch | FAIL |
| [Signals](2026-10-14-signals-design.md) | 6b: a signal action | FAIL |
| [Flanking](2026-10-14-flanking-design.md) | 6c: hunters must surround prey | PASS on two seeds |
| [Brain size](2026-10-14-brain-size-design.md) | 7a: brain size as a gene, flat cost | FAIL, three tries |
| [Brain tax](2026-10-29-brain-tax-design.md) | 7b: the brain as a share of each meal | PASS on two seeds |

| [Hills](2026-10-29-hills-design.md) | 8a: a height map | FAIL |
| [Ambush](2026-10-30-ambush-design.md) | 8b: a viewer's idea, thickets and walking costs | PASS on two seeds; only matches chasing per meal |
| [Omnivores](2026-10-30-omnivore-design.md) | 9a: hunters with a diet gene | FAIL on the second bar; hunters stopped hunting, and a poor gut went further |
| [Gut ladder](2026-10-31-gut-ladder-design.md) | 9b: how bad must a gut be to keep a hunter hunting? | PASS on two seeds; a sharp switch, and few hunters |
